# 工业制造领域故障案例信息抽取

使用UIE（Universal Information Extraction）模型进行工业制造领域的故障案例信息抽取。

## 功能概述

本系统可以从工业制造领域的故障案例文本中自动抽取以下信息：

### 实体类型
- **部件单元**：高端装备制造领域中的各种单元、零件、设备
  - 示例：燃油泵、换流变压器、分离器、发动机盖、发动机盖锁、发动机盖铰链
- **性能表征**：部件的特征或者性能描述
  - 示例：压力、转速、温度、车速、液面
- **故障状态**：系统或部件的故障状态描述，多为故障类型
  - 示例：漏油、断裂、变形、卡滞、抖动、松旷、损坏
- **检测工具**：用于检测某些故障的专用仪器
  - 示例：零序互感器、保护器、漏电测试仪

### 关系类型
- **部件故障**：部件单元 → 故障状态
  - 示例：发动机盖 → 抖动，燃油泵 → 损坏
- **性能故障**：性能表征 → 故障状态
  - 示例：液面 → 变低，车速 → 异常
- **检测工具**：检测工具 → 性能表征
  - 示例：漏电测试仪 → 电流
- **组成关系**：部件单元 → 部件单元
  - 示例：断路器 → 换流变压器

## 文件说明

### 主要脚本文件

1. **`industrial_fault_extraction.py`** - 基础版本的信息抽取器
2. **`advanced_fault_extraction.py`** - 高级版本，包含更复杂的关系抽取逻辑
3. **`fault_extraction_demo.py`** - 演示版本，包含完整的实体和关系抽取功能

### 依赖文件

- `uie_predictor.py` - UIE预测器
- `model.py` - UIE模型定义
- `tokenizer.py` - 分词器
- `utils.py` - 工具函数

## 安装和配置

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 下载模型

首次运行时会自动下载UIE模型，或者手动转换：

```bash
python convert.py
```

## 使用方法

### 1. 基础使用

```python
from fault_extraction_demo import FaultExtractionDemo

# 初始化抽取器
extractor = FaultExtractionDemo(model_name='uie-base', device='cpu')

# 处理单个文本
text = "故障现象:车速到100迈以上发动机盖后部随着车速抖动。"
result = extractor.process_single_text(text, "SAMPLE_001")
```

### 2. 批量处理

```python
# 处理训练数据文件
extractor.process_training_data("train_data.json", "output_results.json")
```

### 3. 运行演示

```bash
python fault_extraction_demo.py
```

## 示例结果

### 示例1：发动机盖抖动故障

**输入文本：**
```
故障现象:车速到100迈以上发动机盖后部随着车速抖动。故障原因简要分析:经技术人员试车；怀疑发动机盖锁或发动机盖铰链松旷。
```

**抽取结果：**
- **实体**：
  - 部件单元：发动机盖、发动机盖锁、发动机盖铰链
  - 故障状态：抖动、松旷
- **关系**：
  - 部件故障：发动机盖 → 抖动
  - 部件故障：发动机盖锁 → 松旷
  - 部件故障：发动机盖铰链 → 松旷

### 示例2：燃油泵损坏故障

**输入文本：**
```
燃油泵的作用是将燃油加压输送到喷油器，当燃油泵损坏后，燃油将不能正常喷入发动机气缸，因此将影响发动机的正常运转，使得发动机出现加速不良的症状，情况严重时将导致发动机无法起动。
```

**抽取结果：**
- **实体**：
  - 部件单元：燃油泵、喷油器、发动机气缸、发动机
  - 故障状态：损坏、加速不良、无法起动
- **关系**：
  - 部件故障：燃油泵 → 损坏
  - 部件故障：发动机 → 加速不良
  - 部件故障：发动机 → 无法起动

## 技术特点

1. **零样本抽取**：无需训练即可进行信息抽取
2. **多任务统一**：实体抽取和关系抽取使用统一的UIE框架
3. **领域适应**：专门针对工业制造领域的故障案例进行优化
4. **高精度**：基于预训练的UIE模型，具有较高的抽取精度
5. **易扩展**：可以轻松添加新的实体类型和关系类型

## 性能优化

1. **GPU加速**：支持GPU推理加速
2. **批量处理**：支持批量文本处理
3. **内存优化**：针对大文本进行内存优化
4. **并行处理**：支持多进程并行处理

## 注意事项

1. 首次运行需要下载模型，可能需要较长时间
2. 建议使用GPU进行推理以获得更好的性能
3. 对于长文本，系统会自动进行分段处理
4. 抽取结果的准确性取决于文本质量和模型性能

## 故障排除

### 常见问题

1. **模型下载失败**
   - 检查网络连接
   - 手动下载模型文件

2. **内存不足**
   - 减少batch_size
   - 使用CPU推理
   - 分段处理长文本

3. **抽取结果不准确**
   - 检查输入文本质量
   - 调整position_prob参数
   - 使用领域特定的训练数据微调模型
